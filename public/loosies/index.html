01Every weekend

The header covers your page titles

Now: the VIP button sits on top of "Upcoming Events."Patched: one row, title's clear. About 15 lines of CSS.

On a regular iPhone the nav wraps onto two rows so the header ends up 194px tall and the VIP Reservations button lands right on the page title. Same thing happens on Table Reservations.

The patched version is your live page with a little CSS I applied in my own browser. Nothing on your site was touched.

02Table requests

The table form is squeezed

Now: the form is 248px wide, about 2/3 of the screen.Patched: full width, 358px.

The SevenRooms form is embedded at width="85%" inside a card that's already padded so on a phone it ends up tiny. This is where your table requests come in so it's worth the five minutes.

The patch (covers 01 and 02) 
@media (max-width: 575.98px) {
  /* logo, VIP button and menu on one row */
  .headroom .navbar > .container { flex-wrap: nowrap; }
  .headroom .navbar-brand { max-width: 120px; }
  .headroom .navbar-brand img { max-height: 44px; width: auto; }

  /* start content below the fixed header */
  main#content > .page-header > .page-section:first-child { padding-top: 140px; }

  /* full-width table form */
  .content-blocks:has(iframe.lounge-form) { padding-left: 0 !important; padding-right: 0 !important; }
  .page-section:has(iframe.lounge-form) > .container { padding-left: 16px; padding-right: 16px; }
  iframe.lounge-form { width: 100% !important; }

  /* bigger ticket/VIP buttons on event cards (25px tall right now) */
  .event-list-post__buttons .btn { min-height: 44px; display: inline-flex; align-items: center; justify-content: center; }
}

I pulled the selectors from your live pages and tested in Chrome at iPhone size, not on an actual iPhone, so give it a quick QA. The header looks shared across Tao venues so check those too. Also worth adding title="Table reservation request" to the iframe for screen readers.

04AI search

ChatGPT doesn't mention you

I asked ChatGPT "Best clubs in LES NYC?" It gave a top 8 and Loosie's wasn't on it.

ChatGPT, Nov 9  ·  No Loosie's

These answers pull from Yelp, listicles and aggregator sites way more than your own page, and some of what's out there about you is off:

  • Clubbable describes Loosie's as a speakeasy with exposed brick, jazz and indie rock.
  • Search snippets still show Thu–Sat hours. Your page says Thu–Sun.
  • Dress code, how to get in and directions aren't on your site so aggregators answer those for you.
  • Your events list only loads with JavaScript so crawlers that don't run it see an empty calendar. Discotech's event pages outrank yours for stuff like "Friday club LES."

How to show up more

  1. Claim and fill out Yelp. ChatGPT's place cards pull from it (that's the Yelp rating on Home Sweet Home above).
  2. Say what you are on your own page in plain words. Basement dance club under the Moxy, what music plays which night, Thu–Sun till 4, 21+, dress code, how to get in.
  3. Make the events list readable without JavaScript so every night has a page crawlers can actually see.
  4. Get the wrong info fixed. Ask Clubbable to update their description and make sure your Google hours say Thu–Sun.
  5. Get on the lists these answers cite. Discotech's LES list already has you. Time Out's LES nightlife page hasn't been updated since 2016.

Happy to draft the "plan your night" copy if that's useful.
