Three quick fixesbefore this weekend

I was checking out Loosie's on my phone and noticed a few things getting in the way of people booking. So I dug in and wrote up the fixes. Your web team can ship all three in an afternoon.

Nathan Ortiz · Nov 9, 2026 · public pages only, nothing logged into or submitted

  1. On iPhones, the header sits on top of the page title on the Events and Table Reservations pages.
  2. The table request form is squeezed to 248px, about two-thirds of the screen.
  3. The New Year's Eve "VIP Reservations" button is broken. The link is pasted in twice. One-field fix.
01 · Every weekend

The header covers the title on phones

On a standard iPhone (390px wide) the nav wraps onto two rows. The fixed header ends up 194px tall and the "VIP Reservations" button lands right on "Upcoming Events" and "Table Reservations." The "after" shots are your live pages with a small CSS patch I applied in my own browser. Nothing on your site was touched.

02 · Table requests

The table form is squeezed

The SevenRooms form is embedded at width="85%" inside a card that's already padded, so on a phone it ends up 248px wide and the name and email fields get cramped. The same patch makes it full width (358px). This is the form your table bookings come through, so it's worth the five minutes.

The patch (CSS, mobile only) 
@media (max-width: 575.98px) {
  /* logo, VIP button and menu on one row */
  .headroom .navbar > .container { flex-wrap: nowrap; }
  .headroom .navbar-brand { max-width: 120px; }
  .headroom .navbar-brand img { max-height: 44px; width: auto; }

  /* start content below the fixed header */
  main#content > .page-header > .page-section:first-child { padding-top: 140px; }

  /* full-width table form */
  .content-blocks:has(iframe.lounge-form) { padding-left: 0 !important; padding-right: 0 !important; }
  .page-section:has(iframe.lounge-form) > .container { padding-left: 16px; padding-right: 16px; }
  iframe.lounge-form { width: 100% !important; }

  /* bigger ticket/VIP buttons on event cards (currently 25px tall) */
  .event-list-post__buttons .btn { min-height: 44px; display: inline-flex; align-items: center; justify-content: center; }
}

Also worth adding title="Loosie's table reservation request" to the iframe for screen readers. I pulled the selectors from your live pages tonight and tested in Chrome at iPhone size, but not on an actual iPhone, so give it a quick QA. The header looks shared across Tao venues, so check those too.

Bonus

What Google and AI answers say about Loosie's

I also checked how Loosie's shows up when people search or ask an AI for clubs in the LES. Most answers pull from third-party sites, not yours, and a few of those get things wrong:

  • Clubbable calls Loosie's a speakeasy with exposed brick, jazz and indie rock.
  • Discotech's listing has a reservations email from a different hospitality company. That matters because Discotech is behind most of Loosie's mentions in "best LES clubs" results.
  • Search snippets still show Thu–Sat hours. Your page says Thu–Sun.
  • Dress code, how to get in and directions aren't on your site, so aggregators answer those instead.
  • Your events list only loads with JavaScript, so crawlers that don't run it see an empty calendar. Discotech's event pages outrank yours for stuff like "Friday club LES."

No tricks needed here. Put the real answers on your own page (a short "plan your night" section), make the events list readable without JS, and ask those two sites to fix their info. Happy to draft the copy if that's useful.
