Three fixes for Loosie's, before New Year's Eve.

I looked at Loosie's the way a guest does: on a phone, and through what Google and AI assistants say about it. A few small things are getting between guests and a booking. Each fix below is ready for your web team.

Nathan Ortiz · public pages only, no logins, nothing submitted · checked Nov 9, 2026 (10pm ET)

  1. The New Year's Eve "VIP Reservations" button is broken. It points to a malformed URL, both on the events page and on the NYE event page. It's a one-field fix.

Fix 02 · Mobile

The header covers the title on phones

At 390px wide (iPhone 12–16), the venue nav wraps onto two rows. The fixed header becomes 194px tall, and the "VIP Reservations" pill lands on top of "Upcoming Events" and "Table Reservations." The "after" shots are the same live pages with a small CSS patch applied in my browser. Nothing on your site was changed.

Fix 03 · Table requests

The table form is squeezed

The SevenRooms form is embedded at width="85%" inside a card that's already padded. On a 390px phone, that leaves a 248px form, so name and email fields are cramped. The same patch makes it full-width (358px). It also adds an accessible title to the frame.

The patch (CSS, ~15 lines, mobile only) 
@media (max-width: 575.98px) {
  /* Logo, VIP button and menu on one row */
  .headroom .navbar > .container { flex-wrap: nowrap; }
  .headroom .navbar-brand { max-width: 120px; }
  .headroom .navbar-brand img { max-height: 44px; width: auto; }

  /* Start content below the fixed header */
  main#content > .page-header > .page-section:first-child { padding-top: 140px; }

  /* Full-width table form */
  .content-blocks:has(iframe.lounge-form) { padding-left: 0 !important; padding-right: 0 !important; }
  .page-section:has(iframe.lounge-form) > .container { padding-left: 16px; padding-right: 16px; }
  iframe.lounge-form { width: 100% !important; }

  /* Thumb-sized ticket and VIP buttons on event cards (now 25px tall) */
  .event-list-post__buttons .btn { min-height: 44px; display: inline-flex; align-items: center; justify-content: center; }
}

Plus on the iframe: title="Loosie's table reservation request". Selectors came from the live pages on Nov 9, 2026. I tested in Chrome at 390×844 but not on real iOS Safari, so please QA before shipping. The shared header may be used across other Tao venues, so check them too.

Beyond this week

What Google and AI answers say about Loosie's

When people ask search engines or AI assistants about LES clubs, the answers lean on third-party pages, not on taogroup.com. Those pages get some facts wrong:

  • Clubbable describes Loosie's as a speakeasy with exposed brick, jazz and indie rock.
  • Discotech's listing shows a reservations email at another hospitality company's domain. Discotech also supplies most of Loosie's mentions in "best LES clubs" results.
  • Search snippets still show Thu–Sat hours. Your page says Thu–Sun, 11PM–4AM.
  • Dress code, entry options and directions aren't on the official page, so aggregators answer those questions instead.
  • The events list loads only via JavaScript. The page's HTML contains no event links, so crawlers that don't run scripts see an empty calendar. Discotech's event pages outrank yours for "Friday club LES" searches.

The fix here isn't tricks. Put the true answers in plain text on your own page (a short "Plan your night" block), make the event list readable without JavaScript, and ask the two listings to correct their facts. I'm happy to draft the copy for your approval.

Series name and performer type are assumptions, so adjust them to match how you bill the night. Add price and currency to offers if you want them shown. Run the result through Google's Rich Results Test.
